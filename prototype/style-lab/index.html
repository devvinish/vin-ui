How the header switch will work on the real site

    
One choice, remembered, used everywhere.

    

      
01
Choose once
Style and accent live in the sticky header on every page. Your choice is saved, so the next page and your next visit open the same way.

      
02
Everything follows
Component previews, the hub grid, code tabs (HTML, React, Vue, Svelte), the CLI command and the copy buttons all output the chosen style and accent.

      
03
Shareable
The URL carries your choice too (for example ?style=tactile&accent=0d9488), so you can send someone exactly what you see.
