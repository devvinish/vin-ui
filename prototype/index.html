How it works

Three choices, then it's your code.

No runtime package to keep updated. The component files land in your project, so you can change anything.

01

Pick a style

Minimal, Glass or Brutalist. Every component exists in every style.

02

Pick a framework

Plain HTML + CSS, React, Vue or Svelte. Same API and names everywhere.

HTMLReactVueSvelte
03

Copy or install

Copy from the docs, or let the VinUI CLI add the files for you.

$npx vin-ui add button
The idea

Same markup. Different personality.

Your code never changes between styles. A style is a set of design tokens, so switching is one attribute, not a rewrite.

minimaldata-vin-style="minimal"
Live
glassdata-vin-style="glass"
Live
brutalistdata-vin-style="brutalist"
Live
index.html — identical in all three
<!-- the only line that changes -->
<html data-vin-style="glass">

<button class="vin-btn">Save changes</button>
<button class="vin-btn vin-btn--outline">Cancel</button>

Why VinUI

Built for developers who want choice.

You own the code, you choose the look, and it works in the framework you already use.

You own the code

Components are copied into your project. No lock-in, no breaking updates.

Real styles, not just colours

Shape, borders, shadows, type and motion all change per style.

Any framework

HTML + CSS, React, Vue and Svelte with the same names and props.

Accessible by default

Keyboard support, focus rings, ARIA and WCAG AA contrast in every style.

Accent colour, your way

Pick any accent colour and every component, preview and code sample follows it.

AI-ready soon

llms.txt and an MCP server so AI coding tools can find and add components.
