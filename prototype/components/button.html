Button

Triggers an action or event, such as submitting a form or opening a dialog. Five variants and three sizes, identical in every style and framework.

Sizes

Three sizes. Heights are fixed in every style (30, 36 and 44 px), so swapping styles never breaks your layout.

API

Same props in every framework. In plain HTML, each prop maps to a class.

PropValuesDefaultHTML class
variantprimary · secondary · outline · ghost · dangerprimaryvin-btn--{variant}
sizesm · md · lg · iconmdvin-btn--{size}
disabledbooleanfalsedisabled attribute
asChild / hrefrender as a link or your router's Link—use <a class="vin-btn">

Accessibility

  • Uses a native <button>, so Enter and Space work with no extra JavaScript.
  • Visible focus ring in every style, in light and dark mode.
  • Icon-only buttons need an aria-label. The docs linter warns you.
  • Text contrast meets WCAG AA (4.5:1) in every style and mode.
  • disabled is a real attribute, not just a grey colour.
